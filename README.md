# legal-doc-generator

**ZLC 法律文书自动生成系统** — 纯浏览器端，零服务器依赖。

输入案件信息 → 自动生成 4 份 `.docx` 法律文书，保留律所原始模板的 logo、格式和排版。

## 立即使用

👉 **[打开网页生成](https://seascat.github.io/legal-doc-generator/)**

## 技术原理

- **100% 浏览器端**：所有处理在本地完成，数据不上传
- **JSZip**：解压/重新打包 `.docx`（本质是 ZIP 文件）
- **XML 替换**：直接操作 `word/document.xml`，保留全部格式
- **GitHub Pages**：静态托管，无需服务器
